# 分区夜间最小流量业务实现规格 (Spec)

## 1. 概述
实现分区“夜间最小流量”业务。该业务从配置端驱动，基于 TDengine 5分钟聚合表动态查询分析，前端通过左侧“扁平化虚拟树形表格”和右侧“地图占位”进行分屏展示，支持通过抽屉下钻查看分区趋势及报警详情，兼顾十万级数据渲染性能和层级展示需求。

## 2. 系统配置与后端实现
### 2.1 参数配置
- 在系统参数表 (`sys_config` 或类似表) 中增加两个键值：
  - `zone.night.flow.start`: 默认值 `02:00`
  - `zone.night.flow.end`: 默认值 `04:00`
- 提供对应的后台管理页面/接口，允许管理员修改时间段。

### 2.2 数据查询层 (TDengine)
- **拒绝定时固化策略**：为了解决历史配置变更和数据延迟到达的问题，不创建实体的 `zone_night_flow_1d` 表。
- **实时动态查询**：通过动态 SQL 在 `zone_meters_5m` 表中查出该时间段内的最小值。
  - SQL 示例：
    ```sql
    SELECT zone_code, MIN(total_val) as min_flow
    FROM water_iot.zone_meters_5m 
    WHERE metric_type = 'min_flow' 
      AND ts >= 'YYYY-MM-DD {start}' 
      AND ts <= 'YYYY-MM-DD {end}'
      AND zone_code IN (...) 
    GROUP BY zone_code
    ```
- **批量接口**：提供 `/api/zone-night-flow/batch` 接口，接收前端传来的当前视口可见的 `zone_code` 数组，返回这些分区的“今日夜小”、“昨日夜小”、“插值”、“比率”。

## 3. 前端主视图交互与布局
### 3.1 总体布局
- **分屏设计**：屏幕 50% 宽度为左侧数据列表，50% 宽度为右侧地图区域（暂时放置地图占位组件，支持事件监听）。

### 3.2 扁平化虚拟树形表格 (左侧)
- **视觉形态**：摒弃传统多列且深度缩进的 Tree-Table。
- **层级表达**：每一行是一个紧凑的卡片，不使用递进式 Padding 缩进。在“分区名称”前固定位置放置 **“层级徽标 (Badge)”**（如 `[L1]`, `[L2]`，并辅以颜色区分）。
- **交互逻辑**：
  - 列表拍平传递给 Virtual Scroller 引擎。
  - 保留行首的展开/折叠（`>` / `v`）图标，点击后动态隐藏/显示其下的子节点。
  - 特殊关注或报警分区：整行背景色变红/高亮。
- **卡片内容**：
  - 第一行：展开箭头 + 层级徽标 + 分区名称（粗体）。
  - 第二行：今日夜小 `xx.xxx` | 昨日夜小 `xx.xxx` | 插值 `+x.xxx` | 比率 `+x.x%`（带红绿箭头趋势）。
- **性能优化**：监听滚动事件（节流），将视口内出现的 `zone_code` 提取并发送给后端进行批量查询。

### 3.3 地图与抽屉联动
- **行点击事件**：点击卡片非展开箭头区域，触发以下行为：
  1. 右侧地图占位组件显示：“已定位到分区：XXX”。
  2. 从屏幕**左侧**边缘滑出一个占宽 `800px`（或 60%）的大抽屉。

## 4. 抽屉视图与动态刷新策略
抽屉内部采用 `100% / 100% / 50% / 50%` 宽度布局，内部组件拥有独立的定时器（Timer）刷新策略：

### 4.1 抽屉模块划分
- **模块 A (100% 宽)**：分区 30 天夜间最小流量趋势图（折线图/柱状图）。
- **模块 B (100% 宽)**：分区 10 天小时表数据趋势图（折线图）。
- **模块 C (50% 宽，左下)**：该分区包含的站点、指标、测点的最新实时数据列表。
- **模块 D (50% 宽，右下)**：该分区的报警数据列表（目前采用模拟数据）。

### 4.2 独立刷新策略 (Staggered Refresh)
- **主列表 (视口内)**：每 5 分钟轮询一次。
- **抽屉模块 A & B (趋势图)**：历史聚合数据，不轮询，仅在抽屉 `onOpen` 或用户手动点击刷新时拉取。
- **抽屉模块 C (最新数据)**：实时性高，每 30 秒静默轮询更新。
- **抽屉模块 D (报警列表)**：每 15 秒静默轮询更新。

## 5. 待解决的未知事项与边界
- 地图的具体选型（如百度地图/高德/Cesium/Leaflet）暂不确定，本次实现仅提供地图占位组件及交互钩子。
- 报警列表目前由前端模拟生成数据结构，待后续告警系统完善后对接真实接口。
