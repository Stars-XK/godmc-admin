# 代码清理与文档规范 (Code Cleanup and Documentation Rules)

每次在开发过程中，必须严格遵守以下规范：

1. **测试与修复代码的清理**
   - 每次任务完成后，必须检查并删除所有仅用于临时测试的代码（如临时的 `console.log`、测试接口、临时的 mock 数据等）。
   - 针对 bug 修复（fix）产生的中间调试代码，在提交前必须全部清理干净。
   - 保持代码库的整洁，不要遗留无用的注释掉的代码块。

2. **文档存放规范**
   - 所有的说明文档、设计文档（Spec）、计划文档（Plan）等，必须统一放置在 `.trae/docs` 目录下。
   - 严禁将文档散落在项目根目录或其他业务代码目录中。

3. **规则存放规范**
   - 所有的项目级规则、Cursor/Trae 的 Prompt 规则文件，必须统一放置在 `.trae/rules` 目录下。
